# Wine Cellar Data Schema

## wines.json — one object per wine

| Field | Type | Notes |
|---|---|---|
| `id` | string | Slug, e.g. `wine-barolo-villero`. Auto-generated by `merge_wines.py` — don't set by hand. |
| `name` | string | Required. Wine-list style name, not the full label text. |
| `producer` | string | |
| `vintage` | number, or string (e.g. `"NV"` for non-vintage), or null | Use a number for a normal year. Use an uppercase string like `"NV"` when the label has no vintage year (common for NV Champagne/sparkling) or a non-numeric vintage marking. |
| `varietal` | string | Free-text blend detail, e.g. `"80% Grenache, 10% Mourvèdre, 7% Syrah, 3% Cinsault"` or `"100% Erbaluce"`. |
| `grape` | string | Standardized category used for grouping/filtering in the app. Reuse an existing value from the current file when the wine fits — see taxonomy below. |
| `region` | string | e.g. `"Barolo (Villero cru), Piedmont, Italy"` |
| `quantity` | number | Bottles on hand. |
| `price` | number or omit | Only set from an actual receipt/invoice — never estimate a market price into this field. |
| `rating` | number (1-100) or omit | User-entered only. Never fabricate. |
| `drinkFrom` / `drinkTo` | number (year) or omit | Estimated drinking window. |
| `bin` | string or omit | Storage location. User-entered only. |
| `purchaseDate` | string (YYYY-MM-DD) or omit | From receipt only. |
| `purchaseSource` | string or omit | Merchant/winery/gift-giver. From receipt or explicit user statement only. |
| `notes` | string or omit | Free text — context about the bottle, provenance caveats, etc. |
| `addedAt` | number (epoch ms) | Auto-set by `merge_wines.py` for new entries — don't set by hand. |

## drink-log.json — one object per tasting

| Field | Type | Notes |
|---|---|---|
| `id` | string | Auto-generated by `log_tasting.py`. |
| `wineId` | string | The matched wine's `id` from wines.json. |
| `wineName` | string | Snapshot of the name at time of logging (survives even if the wine is later deleted). |
| `producer` | string | Snapshot. |
| `vintage` | number, or string (e.g. `"NV"`), or null | Snapshot. |
| `grape` | string | Snapshot. |
| `dateDrunk` | string (YYYY-MM-DD) | |
| `notes` | string | Occasion, who was there, tasting impressions, food pairing. |
| `loggedAt` | number (epoch ms) | Auto-set. |

## Grape taxonomy (as of last full pass)

Reuse these verbatim when a new wine fits, rather than inventing a near-duplicate label. Fetch the live `wines.json` first to see the current full set, since this list will grow over time — but these are the categories established so far:

- Pinot Noir
- Nebbiolo
- Chardonnay
- Grenache Blend — GSM-style blends (Grenache-dominant, with Syrah/Mourvèdre/Cinsault etc.)
- Grenache / Garnacha — single-varietal Garnacha/Grenache (distinct from a blend)
- Tempranillo Blend
- Cabernet Sauvignon
- Bordeaux Blend (Merlot-based) — adjust the parenthetical to whichever grape actually dominates
- Corvina Blend (Amarone)
- Port Blend (Fortified)
- Erbaluce (Sparkling)

New categories are fine when nothing fits — follow the same "Grape Name" or "Grape Name Blend (detail)" style.

## Drink-window heuristics

Use these as a starting point when a specific critic/producer drinking window isn't findable, then adjust for the specific wine (a Grand Cru or Reserva-tier bottling typically outlasts a village/entry-level wine from the same style):

| Style | drinkFrom | drinkTo |
|---|---|---|
| Barolo / Barbaresco (Nebbiolo) | vintage + 8 | vintage + 25 |
| Red Burgundy (village/1er Cru Pinot Noir) | vintage + 5 | vintage + 15 |
| Red Burgundy (Grand Cru) | vintage + 6 | vintage + 20 |
| New World Pinot Noir | vintage + 2 | vintage + 10 |
| Napa/Bordeaux-style Cabernet blend | vintage + 3 | vintage + 15 |
| Chablis / unoaked Chardonnay | vintage + 2 | vintage + 10 |
| Amarone | vintage + 5 | vintage + 20 |
| Rioja Gran Reserva | vintage + 6 (often ready on release) | vintage + 25 |
| Châteauneuf-du-Pape | vintage + 3 | vintage + 15 |
| Gigondas | vintage + 3 | vintage + 12 |
| Tawny Port | ready within a few years | vintage + 40-50 (very long) |
| Traditional-method sparkling (extended lees aging) | vintage + 2 | vintage + 10-15 |

If in doubt, search for the specific wine + "drinking window" before falling back to these.
